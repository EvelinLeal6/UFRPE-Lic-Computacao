# Controle de Horas e Salário

Este utilitário foi desenvolvido em **C** de forma autoral para realizar o cálculo descritivo de horas diárias trabalhadas e computar o salário final correspondente.

## 🚀 Funcionalidades
- Registro de horas trabalhadas.
- Cálculo automatizado com base na jornada informada.
- Formatação clara dos resultados financeiros.

## 🛠️ Tecnologias
- Linguagem C
- Biblioteca `stdio.h`
