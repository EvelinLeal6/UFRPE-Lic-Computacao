# 📊 Controle de Horas (Euro)

Utilitário em **C** desenvolvido de forma autoral para gerenciamento e cálculo descritivo de horas diárias trabalhadas e projeção do salário mensal em Euros (€).

## 🚀 Funcionalidades
- **Lançamento Diário:** Registro de horas trabalhadas associadas a cada dia do mês (1 a 31).
- **Zerar Memória:** Inicialização automática do vetor para evitar lixo de memória nos cálculos.
- **Relatório Automatizado:** Exibição estruturada dos ganhos por dia útil trabalhado.
- **Métricas Finais:** Totalização de dias trabalhados, soma de horas e valor líquido final a receber.
- **Interface Visual:** Console customizado com cores ANSI (Verde e Amarelo) para destacar os ganhos.

## 🛠️ Especificações Técnicas
- **Linguagem:** C
- **Valor Base:** € 15,50/ hora
- **Estrutura de Dados:** Vetores (arrays) para mapeamento dos dias do mês.
- **Bibliotecas Utilizadas:** `stdio.h`
